# App icon

`app-icon.png` is the transparent source artwork for `src-tauri/icons/`.
Generated with the built-in imagegen tool. Regenerate platform sizes with
`npm run tauri -- icon assets/app-icon.png`.

## Generation prompt

Use case: stylized-concept. Asset type: production desktop app icon for a Death Note notebook app, single square 1024x1024 PNG with a genuinely transparent alpha background. Primary request: one closed black Death Note notebook, isolated. Style: polished restrained 3D icon illustration, bold recognizable silhouette that remains clear at 32px. Composition: centered large notebook occupying about 85% of the canvas, portrait proportions, very slight three-quarter perspective showing a narrow ivory page edge and black spine, all corners visible and not cropped. Materials: matte charcoal-black leather cover with extremely subtle grain and soft silver edge highlights to remain visible on dark system trays; minimal detail. Text (verbatim): "DEATH" on first line and "NOTE" on second line, large ivory-white slightly irregular Gothic lettering on the upper-middle of the cover, accurately spelled, easy to read. Palette: black, charcoal, ivory only. Lighting: soft studio highlights restricted to the object. Constraints: actual transparent background outside the notebook, clean antialiased cutout edges, no opaque backdrop, no checkered background baked into pixels, no square icon tile, no floor or ground shadow, no extra props, no apples, no skulls, no characters, no watermark, no additional text. Deliver a finished bitmap icon, not a mockup sheet.
